# 골드 주석 검수 패치

원본 골드를 유지하면서 확인한 네 품사 교정과 보류 항목을 기록한다. `corrections.json`에 원본 해시·문장·토큰 위치·전후 값·출처, `deferred_reviews.json`에 보류 이유가 있다.

`apply_review.py`는 원본 해시·문장·토큰이 일치할 때만 별도 `gold_corrected.jsonl`을 만든다. 원본을 덮어쓰지 않고 모델 학습이나 파라미터 선택에 사용하지 않는다. 검수판으로 평가하면 같은 예측을 원본과 검수판에 함께 채점해 주석 효과와 모델 변화량을 구분한다. 기존 실험의 중복된 전체 교정판은 삭제하고 작은 패치만 보존한다.
